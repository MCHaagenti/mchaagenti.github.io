# Project Wiki Index

**Scope:** `wiki/`, excluding `wiki/logs/`
**Parent:** [`root-index.md`](root-index.md)

Any file added to or removed from this scope is reflected here in the same commit. These
pages are plain markdown with no frontmatter, written for people. Release history is routed
separately through [`logs-index.md`](logs-index.md).

The site's own pages under `docs/` are not documentation in this sense — they are the
published artifact, served by GitHub Pages, and are described by
[`site-structure.md`](../../wiki/information/site-structure.md) rather than indexed here.
