What every plugin shares

  • One universal jar. No separate SpigotMC, PaperMC, or FoliaMC download. The jar detects the running server at enable time and installs the matching scheduler.
  • Asynchronous by default. Storage never blocks the server thread, and anything touching the Bukkit API is scheduled back onto a thread allowed to touch it.
  • Pluggable storage. SQLite, MySQL, PostgreSQL, or MongoDB, with drivers resolved at runtime rather than shaded into the jar.
